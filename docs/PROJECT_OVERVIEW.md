# Project Overview

This repository contains the development of a real-time UAV Digital Twin system.

Research goals:
1. Real-time synchronization between UAV and virtual twin.
2. Multi-sensor fault diagnosis.
3. Fault severity estimation.
4. Predictive maintenance.
5. Sim-to-real transfer using Isaac Sim.

Development roadmap:
Phase 1: Isaac Sim telemetry generation.
Phase 2: Telemetry gateway.
Phase 3: Digital Twin visualization.
Phase 4: Fault injection.
Phase 5: ML models.
Phase 6: Real UAV integration.
