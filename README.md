# UAV Digital Twin

## Project Title
Real-Time Digital Twin-Based Multi-Sensor Fault Diagnosis and Predictive Maintenance for UAVs

## Vision
Develop a real-time UAV Digital Twin capable of synchronizing with a physical drone, visualizing live state, diagnosing faults, estimating health and supporting predictive maintenance.

## Core Stack
- PX4 / MAVLink
- Python + FastAPI
- WebSocket telemetry
- NVIDIA Isaac Sim
- ROS 2
- Machine Learning
- Digital Twin Dashboard

## Current Telemetry Architecture
PX4 -> MAVLink -> Python Telemetry Gateway -> WebSocket -> Digital Twin
